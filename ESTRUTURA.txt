📊 BANCO DE DADOS MySQL:

Tabelas Criadas (5):
  1. usuarios ........... Usuários do sistema (admin, professor, aluno)
  2. cursos ............. Cursos disponíveis
  3. conteudos .......... Conteúdos por curso/ano/bimestre
  4. atividades ......... Exercícios e tarefas
  5. submissoes ......... Submissões de alunos

Registros Iniciais:
  • 3 usuários de teste
  • 5 cursos técnicos
  • 3 conteúdos de exemplo


═══════════════════════════════════════════════════════════════════════════

🔌 API REST ENDPOINTS (9 rotas):

Autenticação (2):
  POST /api/auth/login ................. Login de usuário
  POST /api/auth/cadastro .............. Registrar novo usuário

Cursos (2):
  GET /api/cursos ....................... Listar cursos
  POST /api/cursos ...................... Criar novo curso

Conteúdos (2):
  GET /api/conteudos/:curso/:ano/:bimestre . Obter conteúdos
  POST /api/conteudos ................... Adicionar conteúdo

Atividades (2):
  GET /api/atividades/:conteudo_id ... Listar atividades
  POST /api/atividades ................. Criar atividade

Saúde (1):
  GET /api/health ....................... Verificar conexão com BD
