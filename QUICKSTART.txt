📋 PASSOS RÁPIDOS PARA COMEÇAR:

1️⃣  INSTALAR DEPENDÊNCIAS
    ────────────────────────────
    npm install


2️⃣  CONFIGURAR BANCO DE DADOS
    ────────────────────────────
    a) Editar arquivo .env com suas credenciais MySQL:
       - DB_PASSWORD = sua senha do MySQL
    
    b) Abrir cliente MySQL (Workbench, phpMyAdmin ou terminal)
    
    c) Copiar todo conteúdo do arquivo: backend/schema.sql
    
    d) Colar e executar no MySQL


3️⃣  INICIAR SERVIDOR
    ────────────────────────────
    npm run dev
    
    Você verá: ✅ Servidor rodando em http://localhost:3000


4️⃣  TESTAR A CONEXÃO
    ────────────────────────────
    Abrir no navegador:
    http://localhost:3000/api/health
    
    Deve retornar:
    { "sucesso": true, "mensagem": "Servidor conectado ao banco de dados" }


5️⃣  ACESSAR A APLICAÇÃO
    ────────────────────────────
    Página Principal:   http://localhost:3000/html/index.html
    Painel Admin:       http://localhost:3000/jl/pj/pj.html
    Testador API:       http://localhost:3000/api-tester.html

🚨 PROBLEMAS COMUNS
    ────────────────────────────
    ❌ "Connect ECONNREFUSED"
       → MySQL não está rodando
       → Verifique credenciais em .env
    
    ❌ "ER_NO_DB_ERROR"
       → Schema.sql não foi executado
       → Execute todo o conteúdo de backend/schema.sql
    
    ❌ "CORS error"
       → Server deve estar em http://localhost:3000
       → Verifique PORT=3000 em .env
